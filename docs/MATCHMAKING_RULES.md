UPDATED CORE RULE
RULE 1 — Match Type Distribution

Within one session, vary the match types:

1. Balanced Match (DEFAULT — around 60%)

Examples:
A + C vs A + C
B + C vs B + C

This is the backbone of the system.

2. Same-Tier Competitive Match (around 25%)

Examples:
A + A vs A + A
B + B vs B + B
C + C vs C + C

Purpose:

* Create a more competitive feeling
* Give players a “finally, this feels evenly matched” moment

3. Fun / Random Match (around 15%)

More flexible, more relaxed, and slightly more random.

Purpose:

* Social reset
* Bonding
* Keep the session light and fun

Why this is better:

The system now covers:

* Fairness
* Competitiveness
* Fun

Most importantly, the session does not feel monotonous.

Guardrails for Same-Tier Matches:

Tier A:
Allowed more freely because stronger players can usually handle more competitive matches.

Tier B:
Mostly safe.

Tier C / beginner level:
Use carefully.
Do not make beginner-only matches too frequent.
If the skill gap inside the beginner group is still too wide, the match can become chaotic.

Ideal rule:
Beginner vs beginner is okay occasionally, but it should not dominate the session.

Additional Rule — No Streak Bias

Avoid giving a player 2–3 consecutive matches that are:

* Too difficult
* Too easy

There should be variety in each player’s session experience.

Simple Implementation

Each round can have a match type label.

Example:

Round 1 → Balanced
Round 2 → Balanced
Round 3 → Same-tier
Round 4 → Balanced
Round 5 → Fun

Then the app or spreadsheet generates matches based on the selected mode.
